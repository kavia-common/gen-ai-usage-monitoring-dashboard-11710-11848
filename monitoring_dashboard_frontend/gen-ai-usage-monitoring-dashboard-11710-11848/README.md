# gen-ai-usage-monitoring-dashboard-11710-11848

This repository contains the frontend for the Gen AI Usage Monitoring Dashboard.

Container: monitoring_dashboard_frontend

How to run locally:
1) cd monitoring_dashboard_frontend
2) npm install
3) npm start

Then open http://localhost:3000 to view the dashboard.

Notes:
- The dashboard uses mock data only; no external services are required.
- Theme: Ocean Professional (blue primary and amber accents, subtle gradients, rounded corners).
- Future integration placeholders are available in src/services/mockData.js (fetchUsage, subscribeToUpdates).
